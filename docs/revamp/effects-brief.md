# BONEYARD effect refinement

Owner request, 2026-09-30: make each effect better. This continues the approved
Desert Salvage Observatory theme and the existing live publication scope.
Baseline source: 9a0c00274286048bbe2353de628d8c776ef5cb27.

Audience and action: curious visitors take a short cinematic ride; builders can pull a
working standalone part directly. The visual experience and portable part are both products.
The direct Pull part path, Full/sound-on preferences, native scrolling, interruptible tour,
real terrain/clock calculations and configured exports remain contracts.

Compared mechanisms: (1) brighter/denser versions of existing drawings, (2) replace the suite
with one uniform shader treatment, (3) develop each technique's own spatial and interaction
character inside the same world. Choose (3). More glow alone obscures form; a uniform treatment
would erase the library's useful variety. No new intro, selector, gate or extra navigation step.

Each main scene gets a distinct improvement: layered warp and hold response; authored sunset
slit-scan depth; terrain survey detail and atmospheric separation; topographic flow with visible
moving drops and an accessible rain burst; a dimensional scan-relief object with a restrained
survey sweep; stronger globe silhouette and real day/night legibility; richer oscilloscope
trace and hold response; a dimensional geometric insignia. Supporting tube, row, sky, greetings,
yard, switch, hyperspace, rings and diagnostic placeholder get corresponding craft improvements.
All new graphics are original code; existing asset/data provenance stays attached.

Phone is a composition target. Use touch/keyboard parity, stable 44px controls, meaningful
state feedback and a designed Still. Calm lowers intensity. Bound tunable resolution/counts.
Keep one host ticker, cancel temporary effects, and release module resources.

Target: four milliseconds of module JS work per active frame in normal installed desktop
Chromium, adaptive backing stores and reduced detail where needed. Measure actual costs;
CPU time does not certify GPU cost, physical-phone thermals or field frame rate. Record honest
exceptions and fix visually weak or expensive effects before release.

Review all 17 standalone modules at desktop and phone sizes, main eight scenes, useful control
responses, Still/task cleanup, resize, parameter mutation, assets, configured export/lift and
no-JavaScript paths. Compare retained baseline stills with regenerated outputs. Publication
uses the existing authorized GitHub Pages destination only; verify source-bound bytes and live
journeys. Cross-browser and physical-device limits remain explicit.
