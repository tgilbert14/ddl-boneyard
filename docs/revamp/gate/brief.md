# Gate rebuild, 2026-10-01

Owner feedback: "gate 2 sucks.. i need you do go all out and ramp it up!!"
Baseline: ec9a2b5edf15f18ee951d173cad15faa788f7100, live GitHub Pages Gate.
This is a focused rebuild within the approved fun retro sci-fi cinematic ride.

The old two-plane slit scan has no physical silhouette, chassis, occlusion or meaningful event.
Its whole-frame 320px ImageData, distant mip blend and Gaussian slit soften the art while the
interface stays sharp. More exposure or a brighter rim cannot fix this composition.

The replacement is an original reactor gateway in a deep hangar: dark dimensional structure,
segmented casing, bevels, inner lip and a bounded luminous sunset interior. The machine must
still read without emissive color. Use the existing authored sunset strip inside the aperture;
use project phosphor/amber tokens honestly for constructed lighting. Crisp Canvas2D geometry
surrounds a bounded texture rather than upscaling the entire scene as pixel art.

Fire gate is one direct, keyboard/touch action with charge, traversal and recovery. Full gets
an authored cinematic response; Calm a gentler energized response; Still a meaningful settled
energized view with no running work. Vertical scrolling, sound/motion preferences, Auto-fly
interruption, direct Pull part, configured exports, source/asset provenance and one host ticker
remain contracts. No generated assets, paid calls, external runtime, extra intro or navigation.

Judge desktop and portrait at actual size: framed physical silhouette, visible depth hierarchy,
readable aperture above the control plate, clear material/emission separation, and smooth
normal-speed motion. Inspect idle, charge, traversal and settled states, then resize/interrupt
and repeat. Reduced detail on phone is preferable to a clipped or muddy desktop composition.

Target <4 ms normal-rate module JS work, with dimensions and state recorded. JS excludes GPU
and raster work; local portrait emulation does not certify physical Android/iOS or thermals.
Publish through the existing owner-authorized Pages workflow after rendered review and actual
control/PNG/HTML checks, then bind live files to the source revision and recheck the live action.
